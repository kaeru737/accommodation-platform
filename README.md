\# Accommodation Platform



숙박 공간 등록, 예약, 리뷰, 찜, 채팅 기능을 포함한 Spring Boot 기반 숙박 예약 웹 서비스 프로젝트입니다.



\## 주요 기능



\- 숙소 등록 및 조회

\- 숙소 예약 관리

\- 리뷰 작성 및 조회

\- 찜 기능

\- 사용자 간 채팅 기능

\- 관리자/호스트 관련 기능



\## 사용 기술



\- Java

\- Spring Boot

\- Spring Data JPA

\- Maven

\- MySQL

\- WebSocket
